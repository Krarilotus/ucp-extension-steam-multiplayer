# Steam Multiplayer

Библиотека RedirectPlay от Sh0wdown позволяет играть в Stronghold Crusader через Steam!

## Использование

### В игре

1. Включите это расширение.
2. Выберите сетевую игру в главном меню.
3. Выберите провайдер Steamworks.

![Steamworks](https://github.com/gynt/ucp-extension-steam-multiplayer/blob/main/locale/image.png?raw=true)

4. Нажмите Host или Join. При создании откроется окно настройки лобби. Выберите Public вместо Friends only и задайте пароль, если хотите играть только со знакомыми. При подключении к защищённому лобби может появиться запрос пароля.

### Через Steam (только подключение)

Можно использовать ссылку «Присоединиться к игре» в профиле Steam. Хозяин сначала создаёт лобби, открывает оверлей Steam сочетанием Shift+Tab и переходит в свой профиль через имя или значок. Щёлкните правой кнопкой по «Присоединиться к игре» и скопируйте ссылку для других игроков. При переходе по ней Steam открывает игру и сразу подключает её к лобби.

### Из командной строки

- `+connect_lobby <lobby id>` — Добавляется Steam. Идентификатор лобби имеет тип uint64.
- `+host_game` — Занимает роль хозяина; все ждут вашего подключения. Если лобби не указано через +connect_lobby, создаёт его.
- `+join_directly` — Подключается к лобби по идентификатору сразу при запуске, без перебора доступных лобби и удобного интерфейса выбора. Если хозяин ещё не отвечает, интерфейс может казаться зависшим. Предпочтительно для закрытых лобби по приглашению.
- `+join_enumerated` — Перечисляет лобби, сравнивает их идентификаторы с указанным и подключается при совпадении. Работает только для публичных лобби и лобби для друзей.

## Известные проблемы

1. Подключение к публичному лобби без пароля может привести к сбою уже идущей игры.
2. Диалоговое окно может скрываться за игрой; нажмите Alt+Tab, чтобы увидеть его.
